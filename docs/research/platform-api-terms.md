## Disagreements found between official sources (not resolved here)

1. **Reddit approval.** Responsible Builder Policy [R-help, UNVERIFIED as live]: approval is required before accessing any Reddit data through the API. Data API Wiki [R-help, UNVERIFIED as live]: free access at 100 QPM per OAuth client id. Data API Terms 1.3 [R1, live]: identification information only. Developer Terms 3.1 [R5, live]: Reddit "may require" App Review "at Reddit's discretion".
2. **X pricing model.** Pricing page: "No subscriptions". Developer Agreement (Last Updated April 27, 2026) VII.B: Paid Services are "a recurring subscription service".
3. **X recent search.** Search page: "Available to all developers". Pricing page names no free tier and bills each post returned.

## YouTube - sources and quotes

- [Y1] https://developers.google.com/youtube/v3/getting-started ("Last updated 2026-11-12 UTC"): "You need a Google Account to access the Google Cloud console, request an API key, and register your application." / "Create a project in the Google Cloud console and obtain authorization credentials so your application can submit API requests." / "If your application will use any API methods that require user authorization, read the authentication guide to learn how to implement OAuth 2.0 authorization."
- [Y2] https://developers.google.com/youtube/v3/determine_quota_cost ("Last updated 2026-11-12 UTC"): "Projects that enable the YouTube Data API have a default quota allocation of 100 search.list calls, 100 videos.insert calls, and 10,000 units per day combined for all other endpoints." / "The search.list and videos.insert methods have their own quota buckets.
